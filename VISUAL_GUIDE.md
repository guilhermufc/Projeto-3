## Ações em Cada Tela

### 🔐 Login
- [ ] Digite nome de usuário
- [ ] Digite senha
- [ ] Clique em "Entrar"
- [ ] Será redirecionado para Feed

### 📰 Feed
- [ ] Veja posts existentes
- [ ] Clique nas categorias para filtrar
- [ ] Veja likes e visualizações
- [ ] Clique no botão **+** (FAB) para criar post
- [ ] Clique no perfil para sair

### ✍️ Criar Post
- [ ] Selecione uma categoria
- [ ] Digite seu conteúdo
- [ ] (Opcional) Selecione uma imagem
- [ ] Clique em "Postar"
- [ ] Será redirecionado para Feed

| Elemento | O que faz |

| ❤️ | Like no post |
| 📌 | Salvar post |
| 👁️ | Visualizações |
| ➕ (botão flutuante) | Criar novo post |
| 🔍 | Buscar posts |
| 🏠 | Ir para home (Feed) |
| 📅 | Ver calendário/eventos |

## Dicas de Uso

✨ **Para melhor experiência:**
- Use em celular ou modo responsivo do navegador
- Categorias filtram o feed em tempo real
- Cada post mostra autor, categoria, conteúdo, imagem (opcional)
- Você pode criar múltiplos posts

🚀 **Funcionalidades em Desenvolvimento:**
- Comentários e respostas
- Busca avançada
- Perfil de usuário
- Sistema de follow
- Notificações push

## Compartilhando Conteúdo

**Boas práticas:**
1. 📚 Use categoria "Leitura" para: livros, artigos, dicas
2. 🎯 Use categoria "Métodos" para: técnicas de estudo, dicas práticas
3. 📝 Use categoria "Registro" para: notas, resumos, diários
