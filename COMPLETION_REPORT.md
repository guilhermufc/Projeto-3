## 🛠️ Stack Tecnológico

**Frontend:**
- ✅ React 19
- ✅ Vite (build rápido)
- ✅ React Router (navegação)
- ✅ Tailwind CSS (estilos)
- ✅ Axios (HTTP)
- ✅ Material Icons

**Backend:**
- ✅ Express.js
- ✅ SQLite (banco de dados)
- ✅ JWT (autenticação)
- ✅ Bcryptjs (senhas)
- ✅ Multer (upload)
- ✅ CORS (segurança)

## 🚀 Como Começar

### Passo 1: Instalar (uma única vez)
```bash
bash setup.sh
```

### Passo 2: Terminal 1 - Backend
```bash
cd backend && npm run dev
```

### Passo 3: Terminal 2 - Frontend
```bash
cd frontend && npm run dev
```

### Passo 4: Abrir Navegador
```
http://localhost:5173
```

### Passo 5: Fazer Login
```
Usuário: usuario123
Senha: 123456
```
