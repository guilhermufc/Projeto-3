# Guia Rápido - EduConnect

## Para começar rapidamente:

### 1. Instalar dependências do backend
```bash
cd backend
npm install
cd ..
```

### 2. Instalar dependências do frontend
```bash
cd frontend
npm install
cd ..
```

### 3. Iniciar o backend em um terminal
```bash
cd backend
npm run dev
```

Você verá: `Server running on http://localhost:3000`

### 4. Iniciar o frontend em outro terminal
```bash
cd frontend
npm run dev
```

Você verá: `Local: http://localhost:5173`

### 5. Abrir no navegador
Acesse: http://localhost:5173

### 6. Login com usuário de teste
- Usuário: `usuario123`
- Senha: `123456`

## Pronto! 🎉

Agora você pode:
- ✅ Fazer login
- ✅ Ver o feed de posts
- ✅ Criar novos posts
- ✅ Selecionar categorias
- ✅ Fazer logout

## Dica
Se receber erro de CORS, certifique-se de que:
- Backend está rodando na porta 3000
- Frontend está rodando na porta 5173
- Ambos os servidores estão iniciados
